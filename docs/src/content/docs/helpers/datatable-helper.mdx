# DataTableHelper 帮助类

## 概述

[DataTableHelper](https://github.com/qiect/Chet.Utils/blob/main/Chet.Utils/Helpers/DataTableHelper.cs) 是一个静态帮助类，为 DataTable 提供了丰富的高级数据处理功能，包括数据转换、数据透视、数据分析、数据导出、数据清洗、数据连接、高级查询等，旨在补充 DataTableExtensions 中未包含的高级功能，提高数据处理的效率和灵活性。

## 主要特性

- 🔄 数据转换（动态对象、JSON 转 DataTable、列名映射、实体映射）
- 📊 数据透视（透视表、高级透视、分组聚合）
- 📈 数据分析（统计计算、分布分析、相关性分析）
- 📤 数据导出（HTML、Excel XML、Markdown）
- 🧹 数据清洗（验证、清洗、填充缺失值、异常值检测、去重）
- 🔗 数据连接（内连接、左连接、全连接、交叉连接、垂直合并、水平合并）
- 🔍 高级查询（SQL 风格查询、全文搜索、正则筛选）

## 数据转换

### ToDynamicList

将 DataTable 转换为动态对象列表。

```csharp
public static List<dynamic> ToDynamicList(DataTable dataTable)
```

**参数：**
- `dataTable`: 源 DataTable

**返回值：** 动态对象列表，每行转换为一个 ExpandoObject

### ToDataTableFromJson

将 JSON 字符串转换为 DataTable。提供两个重载：

```csharp
public static DataTable ToDataTableFromJson(string json)
public static DataTable ToDataTableFromJson(string json, bool preserveTypes)
```

**参数：**
- `json`: JSON 字符串，必须是对象数组格式
- `preserveTypes`: 是否保留 JSON 值的原始类型。`true` 时列类型为 `object`，值保留为 long、double、bool、DateTime 等；`false` 时列类型为 `string`，所有值转为字符串。无参重载默认为 `false`

**返回值：** 转换后的 DataTable

### MapColumns

映射 DataTable 的列名。

```csharp
public static DataTable MapColumns(DataTable dataTable, Dictionary<string, string> columnMappings)
```

**参数：**
- `dataTable`: 源 DataTable
- `columnMappings`: 列映射字典（原列名 -> 新列名）

**返回值：** 映射后的新 DataTable（原表不变）

### ToDataTableFromObjects

将对象列表转换为 DataTable。

```csharp
public static DataTable ToDataTableFromObjects<T>(IEnumerable<T> objects, string tableName = null)
```

**参数：**
- `objects`: 对象列表
- `tableName`: 表名，默认为类型名称

**返回值：** 转换后的 DataTable

### MapToEntityList\<T\>

将 DataTable 中的数据映射为指定类型的实体对象列表。映射关系通过字段映射字典指定，仅处理 DataTable 中存在且目标类型中也存在的属性。

```csharp
public static List<T> MapToEntityList<T>(DataTable dataTable, Dictionary<string, string> fieldMapping) where T : new()
```

**参数：**
- `dataTable`: 源数据表，包含待转换的行数据
- `fieldMapping`: 字段映射字典，键为 DataTable 列名，值为目标类型的属性名

**返回值：** 转换后的实体对象列表

**泛型约束：**
- `T`: 目标实体类型，必须具有无参构造函数

**行为说明：**
- 自动过滤出有效的映射关系：源列存在且目标属性也存在
- 如果没有有效的映射关系，返回空列表并输出警告
- 自动处理 DBNull 值，跳过空值
- 安全类型转换，支持可空类型、string、DateTime、bool、Guid、decimal、Enum 及通用类型转换
- 转换失败时返回目标类型的默认值
- 单行处理出错时记录日志但继续处理其他行

**示例：**

```csharp
using Chet.Utils.Helpers;
using System.Data;

// 定义目标实体类型
public class UserDto
{
    public string UserName { get; set; }
    public int UserAge { get; set; }
    public string UserCity { get; set; }
}

// 创建 DataTable
var table = new DataTable();
table.Columns.Add("name", typeof(string));
table.Columns.Add("age", typeof(int));
table.Columns.Add("city", typeof(string));

table.Rows.Add("张三", 25, "北京");
table.Rows.Add("李四", 30, "上海");

// 定义字段映射（DataTable 列名 → 实体属性名）
var mapping = new Dictionary<string, string>
{
    ["name"] = "UserName",
    ["age"] = "UserAge",
    ["city"] = "UserCity"
};

// 映射为实体列表
List<UserDto> users = DataTableHelper.MapToEntityList<UserDto>(table, mapping);
```

## 数据分析

### CalculateStatistics

计算数值列的统计信息。

```csharp
public static DataStatistics CalculateStatistics(DataTable dataTable, string columnName)
```

**返回值：** `DataStatistics` 对象，包含以下属性：
- `Count`、`Sum`、`Average`、`Min`、`Max`：基本统计量
- `Median`：中位数
- `Mode`：众数（`double?`，无重复值时为 null）
- `Variance`：样本方差
- `StandardDeviation`：标准差
- `Quartile1`、`Quartile3`：第一/三四分位数
- `Range`：极差
- `Skewness`：偏度（正值右偏，负值左偏）
- `Kurtosis`：峰度（正值比正态更尖峭，负值更平坦）

### AnalyzeDistribution

分析指定列的数据分布情况。

```csharp
public static DataDistribution AnalyzeDistribution(DataTable dataTable, string columnName, int binCount = 10)
```

**返回值：** `DataDistribution` 对象，包含：
- `Bins`：直方图分箱列表（`List<HistogramBin>`，每项含 `Min`、`Max`、`Count`、`Percentage`）
- `Skewness`：偏度
- `Kurtosis`：峰度
- `Percentiles`：百分位数字典

### CalculateCorrelation

计算两列之间的相关系数。

```csharp
public static double CalculateCorrelation(DataTable dataTable, string column1, string column2)
```

```csharp
public static List<DataValidationResult> ValidateData(DataTable dataTable, Dictionary<string, Func<object, bool>> validationRules)
```

**参数：**


**参数：**
- `dataTable`: 源 DataTable

### FillMissingValues

填充缺失值，提供四个重载：

**1. 自动填充所有列的缺失值：**

```csharp
public static DataTable FillMissingValues(DataTable dataTable)
```

填充策略：优先向下取第一个非空值，若下方均为空则沿用上方最近的非空值。返回新表，不修改原表。

**2. 按自定义规则填充：**

```csharp
public static DataTable FillMissingValues(DataTable dataTable, Dictionary<string, Func<DataTable, int, object>> fillingRules)
```

**参数：**
- `fillingRules`: 填充规则字典（列名 -> 填充函数，函数接收当前表和行索引，返回填充值）

**3. 指定列用固定值填充：**

```csharp
public static DataTable FillMissingValues(DataTable dataTable, string columnName, object fillValue)
```

**4. 指定列用策略填充：**

```csharp
public static DataTable FillMissingValues(DataTable dataTable, string columnName, FillMethod fillMethod)
```

**FillMethod 枚举：**
- `Previous`: 使用前一个非空值
- `Next`: 使用后一个非空值
- `Mean`: 使用平均值（仅数值列）
- `Median`: 使用中位数（仅数值列）
- `Mode`: 使用众数

### DetectOutliers

检测数值列中的异常值。

```csharp
public static List<int> DetectOutliers(DataTable dataTable, string columnName, OutlierDetectionMethod method = OutlierDetectionMethod.IQR, double threshold = 1.5)
```

**参数：**
- `dataTable`: 源 DataTable
- `columnName`: 列名
- `method`: 检测方法，默认为 IQR
- `threshold`: 阈值（IQR 方法默认 1.5，Z-Score 方法默认 3.0）

**OutlierDetectionMethod 枚举：**
- `IQR`: 四分位距方法，基于 Q1 - threshold×IQR 和 Q3 + threshold×IQR 检测
- `ZScore`: Z 分数方法，基于数据点与均值的标准差倍数检测

**返回值：** 包含异常值的行索引列表

### RemoveDuplicates

移除 DataTable 中的重复行。

```csharp
public static DataTable RemoveDuplicates(DataTable dataTable, string[] keyColumns = null)
```

**参数：**
- `dataTable`: 源 DataTable
- `keyColumns`: 用于判断重复的列名数组，`null` 表示所有列

**返回值：** 去重后的新 DataTable（原表不变）

## 使用示例

### 数据透视示例

```csharp
using Chet.Utils.Helpers;

// 创建销售数据表
var salesDt = new DataTable();
salesDt.Columns.Add("Year", typeof(int));
salesDt.Columns.Add("Product", typeof(string));
salesDt.Columns.Add("Amount", typeof(decimal));

// 添加数据...

// 创建透视表：按年份（行）和产品（列）统计销售额
var pivotTable = DataTableHelper.Pivot(
    salesDt,
    "Year",
    "Product",
    "Amount",
    values => values.Sum(v => Convert.ToDecimal(v))
);
```

### 数据分析示例

```csharp
// 计算统计信息
var stats = DataTableHelper.CalculateStatistics(salesDt, "Amount");
Console.WriteLine($"平均值: {stats.Average}");
Console.WriteLine($"标准差: {stats.StandardDeviation}");
Console.WriteLine($"最小值: {stats.Min}");
Console.WriteLine($"最大值: {stats.Max}");

// 分析分布
var distribution = DataTableHelper.AnalyzeDistribution(salesDt, "Amount", 5);
foreach (var bin in distribution.Bins)
{
    Console.WriteLine($"[{bin.Min:F2} - {bin.Max:F2}]: {bin.Count} ({bin.Percentage:F1}%)");
}

// 检测异常值（IQR 方法）
var outliers = DataTableHelper.DetectOutliers(salesDt, "Amount");
Console.WriteLine($"发现 {outliers.Count} 个异常值");

// 检测异常值（Z-Score 方法）
var zOutliers = DataTableHelper.DetectOutliers(salesDt, "Amount", OutlierDetectionMethod.ZScore, 2.5);
```

### 数据清洗示例

```csharp
// 清洗数据
```

## 注意事项

1. 本类提供 DataTableExtensions 中未包含的高级功能。
2. 基础功能请使用 DataTableExtensions 扩展方法。
3. 大数据量操作时注意内存使用。
4. 数据连接操作会创建新的 DataTable。
5. `MapToEntityList` 要求目标类型具有无参构造函数，类型转换失败时返回目标类型的默认值。
6. `FillMissingValues` 无参重载返回新 DataTable，不修改原表。
